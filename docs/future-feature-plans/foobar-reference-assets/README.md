# Foobar Reference Assets

Album Haven exposes these files from the authenticated Foobar help surface. They are documentation and optional operator-run helpers. Album Haven does not execute them, configure Foobar2000, or register scheduled tasks.

The public copies use explicit parameters and placeholders. They contain no contributor usernames, workstation paths, music-library locations, credentials, or private fixture data.

## Assets

- `how-to-modal-copy.md`: help text shown by Album Haven
- `text-tools-standard-preset.txt`: baseline tab-separated Text Tools preset
- `text-tools-enhanced-preset.txt`: optional richer playback-history preset
- `foobar-internal-setup-summary-2026-05-28.md`: sanitized portable-install observations
- `backup_foobar_db.ps1`: parameterized external backup helper
- `export_text_tools_stats.py`: parameterized Text Tools export normalizer
- `register_foobar_db_task.ps1`: parameterized Windows scheduled-task helper

Review a script before running it. Supply paths that belong to your own installation. Album Haven neither validates nor manages the resulting backups or tasks.
