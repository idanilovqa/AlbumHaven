- **P2 — Loose Tracks leaks hidden sources.** Hiding a loaded source filters album cards but leaves its loose tracks available, including to Edit tags. The new regression fails with both Main and Hoard still visible.
- **P3 — Partial startup counts ignore filters.** Full bootstrap totals override a filtered gallery even when all sources are disabled. The new regression expects zero and receives the unfiltered 120 artists / 900 albums. Full startup totals must apply only to the matching default filter state.
- **P2 — Repeated same-clock warnings inherit dismissal.** Warning identity hashes root, state, and timestamp. Recovery followed by another event with the same clock produces the old dismissed token; a stale dismissal request is also accepted. Two focused regressions fail. New health events need durable distinct identity, while legacy records remain readable and stable.
- **P2 — HTML rendering repeatedly hashes static assets.** Every template response recomputes the runtime asset digest synchronously, despite an existing startup cache. The restored baseline regression observes three digest calls instead of one. Restore startup-owned digest reuse.
- **P2 — Fifth saved-loop waveform remains blank.** Loading five paused rows concurrently evicts and aborts the first request from the four-entry shared cache. No paused playback event redraws that row. A regression using the actual cache renders only four rows. Bound background waveform work without enlarging the shared cache or weakening its limits.
- **P2 — Fixed modal artwork is clipped.** In the real app at 1200 x 430, artwork extends 88 pixels below the modal. The strengthened FTC-GALLERY-032 fails on complete artwork visibility. Sizing must respect available height while retaining a square image, fixed header, and table-only scrolling.

This explains three CI search scenarios. The exact local regression fails with an empty query instead of `neal morse`. Preserve query and requested-artist provenance; do not weaken these E2Es.
- **P2 — Generic dropdown CSS overrides the account menu hover contract.** A late `!important` background rule defeats the approved native rounded navy hover (`#172d43`). FTC-PERMISSIONS-011 reproduces locally. The earlier custom-color-only exemption was insufficient because this is the native default. Preserve the account menu's existing native and themed rules while keeping search suggestions neutral.
- **P2 — Scan return restores an invalid scroll anchor.** Unconditional `preserveScroll` captures geometry while the gallery is hidden and restores it at scrollTop 43. The exact scan-cold case reproduces locally. Restore normal render options while retaining explicitly requested scroll preservation.
- **P2 — Disabled shared Buttons use the wrong cursor.** The generic disabled rule uses `default`, contradicting the approved shared Button contract and the disabled Apply E2E. Restore `not-allowed` with existing disabled behavior.
- **P2 — Saved-loop Play has no visible keyboard focus.** A forced no-outline rule holds background, border, and text constant for hover and all focus states. No alternate focus indicator exists. Preserve the established subtle one-pixel interaction outline; do not classify its regression test as stale. The precise v8 mockup is unavailable in the permitted checkouts, so its pixels are not independently claimed verified.

- **P2 — The new Artist Family panel bypasses Appearance colors.** FTC-APPEARANCE-001 reaches the new panel and observes a gray background instead of the saved white card color. Existing palette selectors still target the superseded family box and chips, leaving the new panel and its selected/hovered artists unmapped. After those mappings are restored, the real browser reveals that the more-specific generic Button background rules still override navigation hover on the new button-based rows; those rows also need the same background-rule exemption as navigation-tree rows. Preserve the existing color expectations and connect the new selectors to those tokens. Its active/inactive appearance check must explicitly select one artist under the approved toggle behavior.

- **P2 — A requested related artist loses albums when the search response arrives.** Read-only browser snapshots show Cosmic Cathedral and Deep Water rendering correctly immediately after selection under `Neal Morse`, then disappearing after the selected-artist response. A regression against the actual Postgres repository payload reproduces the empty primary group.
